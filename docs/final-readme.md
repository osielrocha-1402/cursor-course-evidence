# Evidencia del Curso de Cursor

## Resumen

Repositorio de evidencia técnica creado durante el curso de Cursor AI.

## Objetivos

- Aprender ingeniería de prompts
- Crear reglas de Cursor reutilizables
- Practicar la generación controlada de código
- Aplicar flujos de trabajo de prueba y depuración
- Documentar procesos de desarrollo asistidos por IA

## Estructura del Repositorio

.cursor/rules/
labs/
docs/
checklists/
## Actividades Completadas

- Día 1: Configuración del Repositorio
- Día 2: Reglas e Ingeniería de Prompts
- Día 3: Generación Controlada de Código
- Día 4: Pruebas y Depuración
- Día 5: MCP y Consolidación del Curso

## Aprendizajes Clave

- La calidad de los prompts es importante
- El contexto mejora la calidad de la generación
- La revisión humana sigue siendo esencial
- Las pruebas previenen regresiones
