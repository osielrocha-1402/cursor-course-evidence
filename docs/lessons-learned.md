# Lessons Learned - Day 01

## Introducción

Durante el primer día se realizó la configuración inicial del repositorio de evidencia y la primera práctica utilizando Cursor AI para generación y revisión de código.

---

## Aprendizajes principales

### 1. Cursor responde mejor con prompts específicos

Mientras más claro fue el objetivo del prompt:
- mejor estructura generó
- menos ambigüedad hubo
- menos correcciones fueron necesarias

Los prompts detallados ayudaron a obtener resultados más controlados.

---

### 2. La revisión humana sigue siendo necesaria

Aunque Cursor generó código funcional, fue importante:
- revisar la lógica
- validar condiciones
- analizar posibles errores
- evaluar mantenibilidad

No conviene aceptar código automáticamente sin entenderlo.

---

### 3. Las reglas ayudan a controlar el comportamiento de la IA

La regla `general-workflow.mdc` ayudó a:
- mantener simplicidad
- evitar complejidad innecesaria
- obtener respuestas más organizadas
- controlar el alcance de la generación

---

### 4. Documentar prompts mejora el aprendizaje

Registrar:
- prompts
- resultados
- observaciones

permitió identificar:
- qué instrucciones funcionaron mejor
- cómo mejorar solicitudes futuras
- cómo obtener respuestas más precisas

---

### 5. Cursor también funciona como herramienta de explicación

Además de generar código, Cursor ayudó a:
- explicar lógica
- sugerir mejoras
- detectar posibles problemas
- proponer refactors simples

---

## Conclusión del día

El primer día permitió entender el flujo básico de trabajo con Cursor AI:
- generación
- revisión
- validación
- documentación
- mejora incremental

También se preparó la estructura base que se utilizará durante el resto del curso.
