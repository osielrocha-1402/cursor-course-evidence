# Notas sobre las reglas de Cursor - Día 2

## code-generation.mdc

Objetivo:
Guiar a Cursor para generar código más limpio, seguro y fácil de mantener.

Beneficios clave:
- Mejora la legibilidad
- Reduce la lógica duplicada
- Fomenta la reutilización de funciones
- Promueve una estructura consistente
- Ayuda a evitar complejidad innecesaria

Impacto esperado:
El código generado requerirá menos correcciones manuales y será más fácil de revisar.

## documentation.mdc

Objetivo:
Estandarizar la documentación técnica generada durante las prácticas.

Beneficios clave:
- Mejora la trazabilidad de las solicitudes
- Facilita la revisión de los resultados
- Documenta las decisiones y correcciones
- Ayuda a explicar el código generado con claridad

Impacto esperado:
La documentación será más útil para las revisiones técnicas y como referencia futura.
