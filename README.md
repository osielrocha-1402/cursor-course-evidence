# Cursor Course Evidence

Repositorio de evidencia técnica para el curso de Cursor AI Code Editor.

## Objetivo

Documentar prácticas, prompts, reglas, pruebas y aprendizajes obtenidos durante el curso.

## Estructura

- `.cursor/rules/` → reglas personalizadas de Cursor
- `labs/` → prácticas y laboratorios diarios
- `docs/` → documentación y notas
- `checklists/` → validaciones diarias

## Propósito

Este repositorio NO busca construir un proyecto productivo final.

Su objetivo es demostrar:
- uso correcto de Cursor
- generación controlada de código
- documentación de prompts
- revisión manual
- testing y debugging
- buenas prácticas de desarrollo asistido por IA

## Enfoque de trabajo

El desarrollo realizado durante este curso será incremental y orientado al aprendizaje práctico.

Cada práctica incluirá:
- generación controlada de código
- revisión manual
- documentación de prompts
- validaciones
- refactor progresivo
- pruebas y debugging

Cursor AI será utilizado como herramienta de asistencia al desarrollo, priorizando comprensión técnica y revisión humana sobre generación automática de código.
