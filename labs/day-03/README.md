# Día 3 - Generación de Código Controlada

## Objetivo

Practicar la generación de código controlada con Cursor AI.

El propósito de este laboratorio es:
- Generar código a partir de indicaciones
- Revisar manualmente la solución generada
- Solicitar mejoras
- Validar la mantenibilidad y la legibilidad
- Documentar el flujo completo de la iteración

## Descripción del Laboratorio

Se generará un pequeño servicio de gestión de tickets utilizando JavaScript.

El servicio deberá:
- Crear tickets
- Validar los campos obligatorios
- Asignar niveles de prioridad
- Evitar tickets duplicados
- Actualizar el estado de los tickets

Este ejercicio se centra en la generación controlada y la revisión humana, en lugar de en una arquitectura lista para producción.
